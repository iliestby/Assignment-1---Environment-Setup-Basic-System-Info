Objective
The objective of this assignment is to create and run a simple script that displays basic system information from a terminal.

Files included
system_info.sh: Bash script used to display the required system information.
img1.png: Screenshot showing the script running successfully in my terminal.
README.md: Short explanation of the assignment and how to run the script.
What the script displays
The script displays:

the operating system name and kernel version
the current logged-in user
the current working directory
Commands used
I ran the following commands in my terminal:

cd assignment1_64040/
chmod +x system_info.sh
./system_info.sh
